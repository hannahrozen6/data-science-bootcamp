# data-science-bootcamp

Intensive technical training focused on production-grade SQL querying and advanced statistical analysis using R and the Tidyverse.

## Overview

A dedicated repository documenting my independent technical skills development. Focus areas include advanced database manipulation, production-ready Tidyverse pipelines, and algorithm design. This repository contains notes, exercises solutions, and projects, showcasing my progress.

## Repository Structure

- `bootcamp_progress_log.md`: A daily log of bootcamp progress, including notes, reflections, and key takeaways.

- `core-notes/`: Technical how-tos and reference materials for R, SQL, and data science concepts.

  - `rstudio_rules_and_tips.md`: A comprehensive guide to coding rules, best practices, and tips for using RStudio effectively.
  - `data_science_rules_and_tips.md`: A guide to best practices in data science, including corpus selection, NLP techniques, and data pipeline management.
  - `SQL_rules_and_tips.md`: A guide to SQL coding rules, best practices, and tips for efficient database querying.
